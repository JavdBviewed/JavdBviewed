# 产品上报与隐私边界

JavdBviewed 的产品上报用于兼容性、发版质量和故障趋势分析，不用于收集影片、账号或同步内容。不同产品端独立决定是否提供上报，不能把一个端的默认策略套用到另一个端。

## 当前范围

| 产品端 | 当前状态 | 可发送的前提 |
| --- | --- | --- |
| 浏览器扩展 | 使用既有匿名遥测契约 | 遵守扩展隐私政策与 Server 字段规则 |
| 桌面 / Android / TV | 尚未接入统一产品上报 SDK | 先完成各端设置、文案、队列和隐私审核 |
| 自部署 Cloud | 不向作者 Server 发送实例健康上报 | 未来必须默认关闭，并由运营方明确开启 |

Cloud 内的账号、设备、同步资产、密钥库、快照和运维日志属于部署实例，软件作者不会自动收到这些数据。

## 允许的数据类别

- 版本、发布通道、粗粒度运行时。
- 匿名安装标识，或不含部署者身份信息的随机实例标识（接收端只持久化其不可逆派生值），用于去重和限流。
- 经过 allowlist 审核的布尔能力开关、范围桶指标、短状态码和错误码。

所有客户端必须按端展示开关与说明。手动诊断报告应在发送前展示字段摘要，用户取消即不发送。

## 禁止的数据类别

- 影片 ID、演员、观看记录、播放进度、搜索词、磁力、来源 URL 和页面内容。
- Cloud 同步 payload、账号、设备清单、审计明细、数据库内容和备份。
- 密码、token、cookie、第三方凭据、API key、完整日志、错误堆栈和本地路径。
- Cloud 实例的 IP、hostname、公开域名、User-Agent 或精确地理位置。

## 保留与控制

Server 的当前默认配置为原始遥测事件保留 365 天，请求 IP 相关运营字段保留 90 天。Cloud 实例健康上报不记录 IP、User-Agent 或地理位置；其独立保留与聚合策略会在功能真正发布时同步公布。

有关自部署 Cloud 的完整边界，见 [Cloud 隐私政策](https://github.com/lmixture/JavdBviewed-Cloud/blob/main/PRIVACY_POLICY.md) 与 [Cloud 上报说明](https://github.com/lmixture/JavdBviewed-Cloud/blob/main/docs/TELEMETRY.md)。
